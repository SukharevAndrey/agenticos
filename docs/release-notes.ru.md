# Примечания к выпускам { #release-notes }

Каждое заметное изменение в AgenticOS, сначала самые новые. Эта страница *является*
файлом [`CHANGELOG.md`](https://github.com/vstorm-co/agenticos/blob/main/CHANGELOG.md) из
репозитория — он читается во время сборки, а не копируется, поэтому файл и страница не
могут разойтись.

Формат следует [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), а версии —
[Semantic Versioning](https://semver.org/spec/v2.0.0.html) с одним исключением: AgenticOS
остаётся на основной версии 1, поэтому изменение, на которое экземпляру нужно
отреагировать, выходит в MINOR-выпуске. Перед обновлением прочитайте примечания к
MINOR-выпуску.

Две вещи версионируются отдельно от списка ниже.

!!! info "`SPEC_VERSION`"

    Формат спецификации агента. Его несёт и опубликованный агент, и экспортированный
    YAML клиента, поэтому он движется только вперёд — вместе с миграцией, которая
    сохраняет загрузку старых документов. См.
    [справочник по спецификации](reference/spec.md).

!!! info "Цепочка миграций"

    `backend/alembic/versions/`, сжатый до одного `0001_baseline`. Идентификаторы
    ревизий, названные ниже, описывают, *когда* что-то изменилось, а не файл, который
    ещё существует, — изменения схемы перечислены по тому, что они делают.
