# AgenticOS vs Sauna { #agenticos-vs-sauna }

Sauna от HeyDaily Inc. — проактивный ИИ-коллега для каждого человека. Она читает
почту, календарь, документы и подключённые инструменты, запоминает узнанное и
предлагает работу или выполняет её за вас — в своих веб- и iOS-приложениях, в
iMessage, Slack и по электронной почте. AgenticOS даёт компании столько
агентов, сколько нужно, и у каждого свои инструкции, модель, инструменты, знания,
бюджет и правила доступа, на инфраструктуре, которую компания контролирует.

Если вам нужен один личный помощник, который через десять минут уже разбирает вашу
почту, Sauna быстро пробуется. Если вы хотите сами решать, что может делать каждый
агент, сколько это стоит и где лежат данные, AgenticOS даёт такой контроль.

Страницу ведёт команда AgenticOS. Источники проверены 21 октября 2026 года.
Базовая версия AgenticOS: v1.10.0. Охват Sauna: её открытые страницы с ценами,
безопасностью и конфиденциальностью (политика конфиденциальности обновлена
6 октября 2026 года); тестируемой учётной записи и согласованного договора нет.

## Где AgenticOS идёт дальше { #where-agenticos-goes-further }

### Агенты для компании, а не один помощник на человека { #agents-for-the-company-not-one-assistant-per-person }

У каждого человека своя Sauna, а общий «мозг» компании входит в план Team. В
AgenticOS каждый агент создан для своей задачи: агент по кадровой политике,
помощник по продажам или агент сортировки обращений в поддержку. У каждого свои
инструкции, [возможности](../reference/capabilities.md), коллекции знаний и
бюджет, и один и тот же агент обслуживает всех, кому открыт доступ.

Спецификация агента [версионируется при публикации](../concepts.md#version) и
[экспортируется в YAML](../features.md#exportable-into-your-own-repository) в ваш
git-репозиторий. [Проект](../projects.md) даёт команде и её агентам общие файлы,
инструкции и чаты.

### Данные остаются там, где вы их разместили { #data-that-stays-where-you-put-it }

Sauna — сервис из США: согласно её политике, персональные данные могут
обрабатываться в США и в странах, где работают её субподрядчики, по Стандартным
договорным условиям ЕС. При регистрации она ищет информацию о вас в открытом
интернете и хранит результат в вашем рабочем пространстве. Её сайт и приложение
загружают рекламные пиксели Meta, LinkedIn, Google и Reddit, в некоторых регионах
отключённые по умолчанию. Продуктовая аналитика хранится до семи лет.

AgenticOS хранит диалоги, документы и векторы в
[вашем собственном Postgres](../data-protection.md#where-personal-data-lives), а
свежая установка
[не отправляет наружу ни промптов, ни документов](../data-protection.md#nothing-leaves-by-default);
[диагностика экземпляра](../configuration.md#diagnostics) включена по умолчанию и
её можно отключить. Сроки
[хранения для каждого класса данных](../governance.md#retention) задаёте вы. С
локальной моделью вашему содержимому не нужно покидать вашу сеть.

### Модель на ваш выбор и бюджет на каждого агента { #a-model-you-choose-and-a-budget-per-agent }

Самый дешёвый план Sauna работает на её собственной модели Lite, а выбор моделей
открывается начиная с Basic. Большинство моделей работают без хранения данных;
Claude Fable 5.1 хранит промпты и ответы 30 дней в Anthropic. AgenticOS даёт
[28 провайдеров](../models.md#providers) для каждого агента. У каждого агента есть
[месячный бюджет](../governance.md#budgets), который проверяется
[перед каждым запросом к модели](../governance.md#enforcement-is-before-the-request)
и считается в валюте вашего провайдера, а не в кредитах.

### Согласование не тем, кто просит { #approval-by-someone-other-than-the-requester }

Sauna позволяет задать, сколько она может делать без вас. В AgenticOS инструмент,
для которого автор агента включил согласование,
[приостанавливает запуск](../governance.md#approvals), пока его не решит человек
с `approvals:decide`, и каждое решение попадает в
[журнал аудита с защитой от подмены](../governance.md#audit). У подключения MCP
своя [политика согласования](../mcp.md#which-calls-wait-for-a-person).

### Знания, которые можно проверить { #knowledge-you-can-inspect }

Sauna хранит загруженные файлы и обращается к ним по ходу работы. AgenticOS
добавляет управляемые коллекции документов: вы выбираете
[парсер](../file-processing.md#parser-selection-rag) и
[разбиение на фрагменты](../file-processing.md#chunking-configuration) для каждой
коллекции. Синхронизировать можно из Google Drive, S3, SharePoint или OneDrive, с
сайта или из git-репозитория.

## Когда Sauna достаточно { #when-sauna-is-enough }

- Вам нужен личный помощник, который разбирает вашу почту и календарь, и ничего не
  нужно запускать.
- Вы хотите общаться с ним в iMessage, приложении для iOS или Superhuman. У
  AgenticOS ничего этого нет.
- Её каталога из более чем 3 000 инструментов вместе с вашими MCP-серверами
  хватает для вашей работы.
- Обработка данных в США и её условия хранения вас устраивают.

## Используйте их вместе { #use-them-together }

Оставьте Sauna для почты одного человека. AgenticOS используйте для агентов, на
которых держатся команда или её клиенты. Агент AgenticOS может следить за почтовым
ящиком через [триггер Gmail](../triggers.md#gmail-1-minute-and-no-secret-anywhere),
работать по расписанию как автоматизация, помнить узнанное благодаря
[памяти](../reference/capabilities.md#memory-files) и публиковать
[приложения](../reference/capabilities.md#artifacts) — в пределах бюджетов и
согласований, описанных выше.

## Попробуйте один вопрос из справочника { #try-one-handbook-question }

Возьмите [общий образец документа](../howto/first-document-agent.md). Задайте в
обоих вопрос, на который в документе есть ответ, и вопрос об отсутствующей
политике. Затем передайте ответ коллеге. В Sauna ему нужна своя учётная запись,
либо вы открываете ему доступ к своей Sauna; в AgenticOS он открывает агента,
которому вы открыли доступ, или
[размещённую страницу](../channels.md#a-hosted-page). Запишите результат по
[методике сравнения](comparison.md#a-shared-trial).

## Частые вопросы { #frequently-asked-questions }

### Может ли AgenticOS заменить Sauna? { #is-agenticos-an-alternative-to-sauna }

Да, если вам нужны агенты для команды, а не один помощник на человека. AgenticOS
запускает множество агентов, и у каждого свои инструкции, доступ, знания и бюджет,
на вашей собственной инфраструктуре. Sauna быстрее запускается для почты одного
человека и работает в своём облаке.

### Где Sauna хранит данные? { #where-does-sauna-store-data }

На её странице о безопасности сказано, что для клиентов из США инфраструктура и
хранение данных находятся в США, а политика конфиденциальности говорит, что данные
могут обрабатываться в США и везде, где работают её субподрядчики. AgenticOS
хранит данные на вашем собственном экземпляре, где бы вы его ни запускали:
диалоги, документы и векторы — в вашем Postgres, загруженные файлы и рабочие
пространства песочницы — на его томах, а недолговечное состояние — в Redis.

### Как соотносятся цены? { #how-does-pricing-compare }

У Sauna есть бесплатный план с 10 кредитами в день или 20 с подтверждённой картой и
платные планы от $29 до $999 в месяц с помесячной оплатой. У AgenticOS нет
платы за лицензию: вы платите провайдерам моделей напрямую, и у каждого агента
свой месячный бюджет.

### Может ли AgenticOS читать мою почту, как Sauna? { #can-agenticos-read-my-email-like-sauna }

Агент может, если вы его подключите. Триггер Gmail запускает агента на новое
письмо, а MCP-сервер для вашего почтового ящика позволяет читать и готовить
черновики. Каждая операция записи может ждать согласования.
