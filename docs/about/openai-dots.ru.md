# AgenticOS vs OpenAI dots { #agenticos-vs-openai-dots }

OpenAI dots — постоянно работающие агенты внутри ChatGPT. У каждого dot свой облачный компьютер и браузер, он работает через тысячи подключённых приложений и отвечает в ChatGPT, Slack и Microsoft Teams. AgenticOS даёт такого же коллегу — агента с инструментами, браузером, песочницей и расписанием, — работающего на инфраструктуре, которой вы управляете, с любой моделью и с ограничениями, которые платформа применяет, а не просит их соблюдать.

Если ваша компания уже живёт в ChatGPT и ваш тариф и регион включают dots, это самый быстрый способ попробовать ИИ-коллегу. Если нужно, чтобы агенты, данные и правила оставались вашими, для этого и создан AgenticOS.

Страницу ведёт команда AgenticOS. Источники проверены 21 октября 2026 года. Базовая версия AgenticOS: v1.10.0. Что проверено про dots: анонс OpenAI от 29 сентября 2026 года, его FAQ в справочном центре и публикации прессы, а не протестированная учётная запись.

## Где AgenticOS идёт дальше { #where-agenticos-goes-further }

### Правила, которые применяет платформа { #rules-the-platform-enforces }

OpenAI описывает свои правила как указания, которым следует dot, а рискованные действия проверяет модель. В AgenticOS [согласование](../governance.md#approvals) проверяет платформа до запуска инструмента, что бы ни решила модель, а привязка MCP может [разрешить только выбранные вами инструменты](../mcp.md#which-tools-and-who-decides). [Бюджет](../governance.md#enforcement-is-before-the-request) останавливает запуск до запроса к модели, который его превысил бы.

### Ваши серверы, ваш регион { #your-servers-your-region }

dots работают в облаке OpenAI, и на момент запуска тариф Pro не предлагали в ЕЭЗ, Швейцарии и Великобритании. AgenticOS работает [там, где вы его развернёте](../deploy.md), хранит диалоги и документы в [вашем собственном Postgres](../data-protection.md#where-personal-data-lives) и может работать с [локальной моделью](../models.md#providers), чтобы промпты и документы не покидали вашу сеть.

### Любая модель, а не модель одного вендора { #any-model-not-one-vendors }

dot думает моделями OpenAI. Агент AgenticOS использует [профиль модели](../models.md#a-model-profile) поверх 28 провайдеров, с резервными моделями, поэтому один агент может работать на Claude, другой — на локальной модели, а смена провайдера — это одна настройка.

### Запись, которую можно проверить { #a-record-you-can-audit }

Каждый запуск в AgenticOS находится в [Активности](../governance.md#audit) со своими шагами, стоимостью и исходом, а журнал аудита защищён от подмены. Вход выполняется через ваш [каталог OIDC, LDAP или Kerberos](../directory.md#signing-in-with-a-directory-account).

## Когда dots достаточно { #when-dots-are-enough }

- Ваша компания уже работает в ChatGPT, и ваш тариф и регион включают dots.
- Модели OpenAI, его облако и подключённые приложения отвечают вашим требованиям.
- Вам нужен помощник, который следит за вашими приложениями и предлагает работу, без инфраструктуры, которую надо обслуживать. AgenticOS покрывает работу по расписанию и по событиям [автоматизациями](../features.md#triggers-so-an-agent-runs-without-you), которые кто-то настраивает.

## Частые вопросы { #frequently-asked-questions }

### AgenticOS — альтернатива OpenAI dots? { #is-agenticos-an-alternative-to-openai-dots }

Да, если вы хотите постоянно работающих агентов, которые размещаете сами. У агентов AgenticOS есть инструменты, браузер, песочница для кода и автоматизации, они работают на вашей инфраструктуре с любой моделью и отвечают в веб-чате, Slack, Telegram, Mattermost и через API.

### Может ли AgenticOS работать, пока никто не общается в чате? { #can-agenticos-work-while-nobody-is-chatting }

Да. Автоматизация запускает агента по расписанию или по событию, например по задаче на GitHub (issue), письму или подписанному вебхуку, а её запуски получают бюджет и записываются, как любые другие.

### Где работают dots и где работает AgenticOS? { #where-do-dots-run-and-where-does-agenticos-run }

dots работают в облаке OpenAI. AgenticOS работает на ваших собственных серверах или в вашей облачной учётной записи и хранит свои данные в вашем собственном Postgres.
