# AgenticOS vs OpenAI Codex { #agenticos-vs-openai-codex }

OpenAI Codex — агент для разработки ПО. Он охватывает CLI с открытым исходным
кодом, расширение для IDE, приложение ChatGPT для компьютера, облачные задачи и
проверку пул-реквестов на GitHub. Он для разработчиков, которые меняют код.
AgenticOS — для агентов, которыми пользуется вся организация: бизнес-команды
настраивают их в браузере, управление идёт на сервере, а публикуются они в чат,
в веб и в API.

У них есть общее: лицензия Apache-2.0 для открытых частей, MCP, выполнение в
песочнице и согласование перед рискованными действиями. Применяют они это к
разным пользователям.

Страницу ведёт команда AgenticOS. Источники проверены 21 октября 2026 года.
Базовая версия AgenticOS: v1.10.0. Охват Codex: документация OpenAI о Codex на
learn.chatgpt.com, страница тарифов и репозиторий `openai/codex`; проверенного
корпоративного развёртывания нет.

## Коротко { #at-a-glance }

| Область | OpenAI Codex | AgenticOS |
| --- | --- | --- |
| Для кого | Инженеры-программисты | Бизнес-команды, которые настраивают агентов, и инженеры, которые их расширяют |
| С чем работает | Репозиторий кода и командная оболочка | Документы, инструменты и системы компании |
| Где работает | Машины разработчиков; облачные задачи в контейнерах OpenAI | Ваша инфраструктура, как общий сервис |
| Исходный код | CLI — Apache-2.0; облако, проверка кода и приложение ChatGPT — проприетарные | Apache-2.0 |
| Модели | OpenAI после входа через ChatGPT; CLI также принимает Ollama, LM Studio, Bedrock и собственных провайдеров | 28 провайдеров, задаются в профиле модели |
| Конечные пользователи | Разработчик | Сотрудники, клиенты и системы — через восемь способов доступа |
| Согласования | Режимы песочницы и политики согласования за столом разработчика | Человек с `approvals:decide` из общей очереди |
| Контроль расходов | Лимиты на каждые пять часов на местах Plus и Standard Business и кредиты, общие с ChatGPT Work | Месячный бюджет на каждого агента и на каждую организацию |
| Цена | Входит в каждый тариф ChatGPT, от Free до Enterprise; OpenAI оценивает 100–200 $ на разработчика в месяц при оплате кредитами | Без платы за лицензию; использование моделей и инфраструктура |

## Где AgenticOS идёт дальше { #where-agenticos-goes-further }

### Агенты для тех, кто вне инженерной команды { #agents-for-people-outside-engineering }

Облачные функции Codex требуют тарифа ChatGPT, а его пользователи —
разработчики. Для агентов компании OpenAI предлагает вместо этого агентов
рабочего пространства ChatGPT; см.
[AgenticOS vs ChatGPT](chatgpt.md). AgenticOS даёт бизнес-команде весь путь:
инструкции, [возможности](../reference/capabilities.md), знания, бюджет,
[опубликованную версию](../concepts.md#version) и
[восемь способов доступа](../channels.md).

### Правила, которые действуют сразу для всех { #rules-that-hold-for-everyone-at-once }

Codex применяет политики песочницы и согласования на машине каждого
разработчика, а для парка машин есть управляемый `requirements.toml`. AgenticOS
применяет их один раз, на сервере. [Разрешения](../permissions.md),
[бюджеты](../governance.md#enforcement-is-before-the-request),
[согласования](../governance.md#approvals) и
[журнал аудита](../governance.md#audit) действуют на каждый запуск, каким бы
способом он ни был начат.

### Любая модель со всеми функциями { #any-model-with-every-feature }

CLI Codex может использовать других провайдеров, но его облачные задачи,
проверка кода и Slack требуют входа через ChatGPT и моделей OpenAI. В AgenticOS
каждый провайдер приходит на одну и ту же платформу:
[28 провайдеров](../models.md#providers),
[резервные модели](../models.md#fallbacks) и стоимость, записанная для каждого
запуска каждого агента.

### Выполнение кода как управляемая возможность { #code-execution-as-a-governed-capability }

Codex выполняет команды в песочнице ОС на машине разработчика или в облачном
контейнере. AgenticOS даёт агентам
[Вычисления](../reference/capabilities.md#run-python) — интерпретатор Monty без
сети и файловой системы — и рабочее пространство
[Песочница](../reference/capabilities.md#files-shell) в
[соседних контейнерах](../sandbox.md#isolation-plainly). И то, и другое
включается для каждого агента отдельно, с лимитами и настройкой согласования.

## Когда Codex — подходящий инструмент { #when-codex-is-the-right-tool }

- Работа — это код: параллельные облачные задачи, проверка пул-реквестов и
  работа в CLI в репозитории.
- Вам нужен CLI для кода с открытым исходным кодом, песочницей на уровне ОС и
  сетью, выключенной по умолчанию.
- У ваших разработчиков уже есть места в ChatGPT.

## Используйте их вместе { #use-them-together }

Инженер может с помощью Codex написать, протестировать и проверить новую
[возможность](../howto/add-capability.md): типизированный Python с тестами, в
репозитории, где правила для участников записаны. После слияния она доступна в
конструкторе любого агента в организации. Спецификация агента
[экспортируется в YAML](../features.md#exportable-into-your-own-repository),
поэтому Codex может проверить изменение агента и в пул-реквесте.

Они сходятся и во время выполнения. Агент с возможностью
[агент для работы с кодом](../reference/capabilities.md#coding-agent) отдаёт
работу с кодом в Codex в его собственной песочнице, с входом по API-ключу OpenAI
или через ChatGPT, и каждый шаг появляется в чате по ходу дела. В обратную
сторону: [AgenticOS — это MCP-сервер](../mcp.md#agenticos-as-an-mcp-server),
поэтому Codex может перечислять и запускать агентов компании, читать их запуски
и искать в их базах знаний.

## Частые вопросы { #frequently-asked-questions }

### AgenticOS — альтернатива OpenAI Codex? { #is-agenticos-an-alternative-to-openai-codex }

Нет, они решают разные задачи. Codex — агент для работы с кодом для
разработчиков. AgenticOS — платформа для управляемых агентов, которых создают
бизнес-команды и которыми пользуются все, и агент AgenticOS может отдать работу
с кодом в Codex.

### OpenAI Codex — открытый исходный код? { #is-openai-codex-open-source }

CLI Codex распространяется под Apache-2.0. Облако Codex, проверка кода и
приложение ChatGPT — проприетарные сервисы. AgenticOS целиком под Apache-2.0.

### Может ли Codex помочь расширить AgenticOS? { #can-codex-help-extend-agenticos }

Да. Инженер может с помощью Codex написать и проверить новую возможность на
типизированном Python. После слияния это переключатель в конструкторе любого
агента.

### Могут ли агенты AgenticOS выполнять код? { #can-agenticos-agents-run-code }

Да. Возможность «Вычисления» запускает Python без сети и файловой системы, а
«Песочница» даёт агенту рабочее пространство в изолированных контейнерах. И то,
и другое включается для каждого агента отдельно.
