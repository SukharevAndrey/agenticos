# AgenticOS vs ChatGPT { #agenticos-vs-chatgpt }

ChatGPT Business и Enterprise дают сотрудникам ассистента OpenAI, а в 2026 году к
ним добавились агенты рабочего пространства: общие агенты, которых собирают в
ChatGPT, а запускают в ChatGPT, Slack, по расписанию или по триггеру API. Это
самое близкое к AgenticOS предложение OpenAI. Различия — в том, где всё
работает, какие модели используются и кто может до агента добраться.

AgenticOS работает на вашей инфраструктуре, использует выбранную вами модель и
открывает одного агента через восемь способов доступа, включая виджет для сайта
и API, который возвращает ответ.

Страницу ведёт команда AgenticOS. Источники проверены 21 октября 2026 года.
Базовая версия AgenticOS: v1.10.0. Охват ChatGPT: страницы OpenAI о тарифах,
бизнес-данных, справочном центре и для разработчиков; проверенного рабочего
пространства нет. Агенты рабочего пространства — предварительная версия,
поэтому перед решением проверьте их текущее состояние.

## Где AgenticOS идёт дальше { #where-agenticos-goes-further }

### Агент, до которого может добраться любой, и ответ, который возвращается { #an-agent-anyone-can-reach-with-an-answer-that-comes-back }

Страница OpenAI для разработчиков говорит, что триггер API агентов рабочего
пространства «возвращает 202 Accepted со ссылкой на диалог в ChatGPT», а «ответ
агента сейчас нельзя получить через API». Опрос статуса запуска — в бете. В
материалах OpenAI для агента не упоминаются ни виджет, ни Telegram, ни
Mattermost.

Агент AgenticOS отвечает через [HTTP API](../channels.md#the-public-api) и
возвращает результат, передаёт поток по [WebSocket](../channels.md#the-raw-websocket) и
встраивается в ваш сайт как [виджет](../channels.md#the-website-widget).
[Размещённая страница](../channels.md#a-hosted-page) — это ссылка для любого.
Боты [Slack, Telegram и Mattermost](../channels.md#slack) работают от имени
связанного человека, который их спросил.

### Модель выбираете вы { #the-model-is-your-decision }

ChatGPT работает на моделях OpenAI. AgenticOS подключает
[28 провайдеров](../models.md#providers) — среди них OpenAI и Azure OpenAI, а
также Anthropic, Google, Mistral, Bedrock и модели на собственных серверах.
Когда где-то появляется модель лучше или дешевле, вы меняете один
[профиль модели](../models.md#a-model-profile). Ничего не нужно публиковать
заново.

### Бюджет на каждого агента { #a-budget-per-agent }

Ограничения OpenAI действуют на рабочие пространства, группы и пользователей, и
OpenAI отмечает, что лимит перерасхода, равный нулю, «не гарантирует» баланс
кредитов в реальном времени. В AgenticOS у каждого агента свой
[месячный бюджет](../governance.md#budgets), который проверяется
[перед каждым запросом к модели](../governance.md#enforcement-is-before-the-request)
и считается в валюте вашего провайдера, а не в кредитах.
[Экран расходов](../governance.md#what-the-cost-screen-shows) показывает, сколько
потратил каждый агент.

### Корпоративные средства контроля в каждом экземпляре { #enterprise-controls-in-every-deployment }

В ChatGPT SCIM, ролевое управление доступом, Compliance API и регионы хранения
данных доступны только на Enterprise. AgenticOS поставляет
[сопоставление групп каталога](../directory.md#directory-group-mappings), шесть
встроенных [ролей с выданными доступами к отдельным ресурсам](../permissions.md#layer-3-visibility-and-grants),
[журнал аудита, защищённый от подделки](../governance.md#audit) и
[сроки хранения по классам данных](../governance.md#retention) в продукте под
Apache-2.0. Пользовательских ролей и SCIM пока нет. Ваши данные остаются там, где
вы развернули систему.

### Платформа, которая не меняется у вас под ногами { #a-platform-that-does-not-move-under-you }

В июне 2026 года OpenAI объявила, что Agent Builder, часть AgentKit, будет
закрыт 30 ноября 2026 года. Платформа Evals и сохранённые объекты промптов
прекращают работу в тот же день. Платформа на собственной инфраструктуре
меняется тогда, когда вы её обновляете.
[Спецификация агента](../reference/spec.md) версионирована и развивается только
вперёд, поэтому спецификация, экспортированная сегодня, загрузится и после
обновления.

## Когда ChatGPT достаточно { #when-chatgpt-is-enough }

- Вам нужны ассистент, глубокое исследование, режим агента и Codex в одной
  подписке — и ничего не нужно запускать.
- Каталог плагинов покрывает нужные вам системы.
- Вам нужны сертификаты OpenAI, управление ключами или партнёрские интеграции
  Compliance API.
- Вам уже сейчас нужны SAML или SCIM, которых в AgenticOS пока нет.

## Используйте их вместе { #use-them-together }

Оставьте ChatGPT для собственной работы сотрудников. AgenticOS берите для
агентов, которые обслуживают клиентов, работают за вашим API или требуют
бюджета и согласующего человека. Добавьте профиль модели OpenAI — и эти агенты
будут работать на тех же моделях под вашим контролем. Для собственных агентов профиль
может [работать на вашей подписке ChatGPT](../models.md#running-on-a-chatgpt-subscription)
вместо API-ключа, а [агент для работы с кодом](../reference/capabilities.md#coding-agent)
отдаёт работу с кодом в Codex в песочнице.

## Частые вопросы { #frequently-asked-questions }

### AgenticOS — альтернатива ChatGPT Enterprise на собственной инфраструктуре? { #is-agenticos-a-self-hosted-alternative-to-chatgpt-enterprise }

Для агентов, которыми владеет ваша организация, — да. AgenticOS работает на
вашей инфраструктуре, использует OpenAI или любого другого провайдера и
открывает каждого агента через восемь способов доступа, с собственным бюджетом и
историей запусков. Но ChatGPT как ассистента для каждого сотрудника он
не заменяет.

### Может ли AgenticOS использовать модели OpenAI? { #can-agenticos-use-openai-models }

Да. Добавьте профиль модели для OpenAI или Azure OpenAI. Позже агента можно
перевести на другого провайдера, не публикуя его заново.

### Чем агенты рабочего пространства ChatGPT отличаются от агентов AgenticOS? { #how-are-chatgpt-workspace-agents-different-from-agenticos-agents }

Агенты рабочего пространства работают в облаке OpenAI на моделях OpenAI — в
ChatGPT, Slack, по расписанию и через триггер API, ответ которого нельзя
получить через API. Агенты AgenticOS работают на вашей инфраструктуре, на любой
модели, и отвечают через API, который возвращает результат, через виджет,
размещённую страницу и чат-ботов.

### Что заменит Agent Builder от OpenAI после его закрытия? { #what-replaces-openais-agent-builder-after-it-shuts-down }

OpenAI направляет пользователей к Agents SDK или к агентам рабочего пространства
ChatGPT. AgenticOS — альтернатива, если вам нужен конструктор, который вы
размещаете у себя, с форматом спецификации, который продолжает загружаться после
обновлений.
