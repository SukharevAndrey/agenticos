# AgenticOS vs Wonderful { #agenticos-vs-wonderful }

Wonderful продаёт закрытую корпоративную ИИ-платформу вместе с командами
внедрения, которые создают агентов внутри вашей организации и поэтапно передают
владение. AgenticOS — открытая платформа, которой ваша организация владеет с
первого дня. Его исходный код под Apache-2.0, он работает на вашей инфраструктуре,
а помощь Vstorm во внедрении оговаривается отдельно.

Вопрос не столько в том, чьё программное обеспечение лучше, сколько в том, чем вы
хотите владеть по завершении проекта: договором с вендором платформы или самой
платформой.

Страницу ведёт команда AgenticOS в Vstorm. Источники проверены 21 октября
2026 года. Базовая версия AgenticOS: v1.10.0. Охват Wonderful: его открытые страницы об
ИИ-операционной системе, развёртывании, агентах, шлюзе и безопасности, а также
анонс финансирования; согласованного договора и тестируемой учётной записи нет.

## Коротко { #at-a-glance }

| Область | Wonderful | AgenticOS |
| --- | --- | --- |
| Что вы покупаете | Платформу вместе с командами внедрения и стратегами | Программное обеспечение, которое запускаете вы; помощь во внедрении оговаривается отдельно |
| Исходный код | Проприетарный; экспорт агентов и конфигурации через его интерфейс или API | Apache-2.0; вся платформа доступна для чтения и ответвлений |
| Где работает | SaaS для нескольких организаций, выделенный экземпляр, ваше облако или изолированная установка на собственных серверах | Ваша инфраструктура, с Docker Compose |
| Цена | Не публикуются; продажи через менеджеров | Без платы за лицензию; модели, инфраструктура и любые согласованные услуги |
| Каналы | Голос, чат, электронная почта, документы и другие каналы | Веб-чат с голосовыми звонками, виджет для встраивания, размещённая страница, HTTP API, WebSocket, Slack, Telegram, Mattermost |
| Модели | Платформа направляет запросы по задачам | Ваш выбор из 28 провайдеров, задаётся в профиле модели |
| Управление | ИИ-шлюз с лимитами бюджета на команду и журналами аудита | Бюджеты на агента и на организацию, согласования и журнал аудита с защитой от подмены |
| Заявленное соответствие | SOC 2 Type II, ISO 27001:2022, PCI DSS, GDPR, соответствие EU AI Act | Ваши механизмы контроля на вашей инфраструктуре; см. [безопасность](../security.md) |

## Где AgenticOS идёт дальше { #where-agenticos-goes-further }

### Вы владеете платформой, а не лицензией на неё { #you-own-the-platform-not-a-licence-to-it }

Wonderful описывает экспорт агентов, навыков, инструментов и настроек управления, а
также API без пользовательского интерфейса. Это серьёзное обязательство. Но среда
выполнения остаётся закрытой, поэтому экспортированному агенту всё равно нужно
где-то работать.

В AgenticOS среда выполнения — как раз то, чем вы владеете. Исходный код под
Apache-2.0, спецификации
[экспортируются в YAML](../features.md#exportable-into-your-own-repository) в ваш
репозиторий, а данные лежат в хранилищах, которые запускаете вы: Postgres, а также
тома для медиафайлов и рабочих пространств, [которые покрывает резервная
копия](../deploy.md#backups). Если вы расстанетесь с Vstorm, экземпляр продолжит
работать, и им сможет управлять другая команда.

### Модель затрат, которую видно до подписания { #a-cost-model-you-can-see-before-you-sign }

Wonderful не публикует цены. У AgenticOS нет платы за лицензию и за место.
Вы платите провайдерам моделей по их тарифам,
[экран расходов](../governance.md#what-the-cost-screen-shows) показывает, сколько
потратил каждый агент, а [бюджеты](../governance.md#budgets) останавливают агента
перед следующим запросом к модели, как только он достигает своего лимита. Объём
работ с Vstorm согласуется для каждого проекта.

### Знания остаются в вашей команде { #your-team-keeps-the-know-how }

Модель работы Wonderful предполагает поэтапный переход от работ под руководством
Wonderful к владению клиентом. AgenticOS устроен так, чтобы ваши люди могли менять
агентов с самого начала. Бизнес-владелец правит инструкции и публикует
[версию](../concepts.md#version). Инженер добавляет
[возможность](../howto/add-capability.md) на типизированном Python, и она
появляется для общего пользования.

### Механизмы контроля, которые можно проверить { #controls-you-can-inspect }

Сертификаты Wonderful относятся к его собственному сервису. В AgenticOS вы
проверяете сами механизмы контроля:
[каталог разрешений](../permissions.md),
[хранилище секретов](../secrets.md#envelope-encryption),
[журнал аудита](../governance.md#audit) и его хеш-цепочку, а также
[тесты отказов](../security.md#the-refusals-as-a-set), которые выполняются в CI.
[Профиль HIPAA](../security.md#the-hipaa-profile-and-what-it-does-not-claim) и
команда `data-protection-report` дают доказательства для одного экземпляра. Ваша
сертификация относится к вашему экземпляру.

## Когда Wonderful подходит лучше { #when-wonderful-is-the-better-fit }

- Вы хотите, чтобы вендор отвечал за внедрение от начала до конца, во многих
  странах и на многих языках.
- Основной сценарий — голосовые агенты для клиентов по телефону. AgenticOS
  принимает [голосовые звонки](../voice.md) только в браузере, и у него нет канала
  телефонии, WhatsApp или SMS.
- Вам нужны собственные сертификаты вендора, например SOC 2 Type II и PCI DSS,
  а не ваши механизмы контроля.

## Вопросы к соглашению о внедрении { #questions-for-the-delivery-agreement }

Задайте обоим вендорам одни и те же вопросы.

| Область | Что согласовать до пилота |
| --- | --- |
| Инфраструктура | Где работает каждый компонент, и кто его обновляет и восстанавливает? |
| Данные и доступ | Какие сервисы получают данные, и кто поддерживает идентичности и учётные данные? |
| Процесс | Кто определяет задачу, разбирает исключения и принимает результаты? |
| Поддержка | Кто разбирает инциденты, и при каком согласованном покрытии? |
| Выход | Какой код, конфигурацию и данные клиент может сохранить, и может ли он продолжать работать без вендора? |

С AgenticOS компания Vstorm может обсудить установку на инфраструктуре клиента,
документацию, проектирование процессов и заказную разработку. Поддержка,
обслуживание, интеграции и обязательства по реакции согласуются для проекта; они
не поставляются вместе с репозиторием автоматически.

Определите одну проверяемую задачу по
[примеру с документом](../howto/first-document-agent.md) и
[руководству по эксплуатации](../rollout.md). За помощью во внедрении обратитесь
в [Vstorm](https://vstorm.co/) или к Kacper. Сравните согласованный объём
внедрения с [критериями для программного обеспечения](comparison.md).

## Частые вопросы { #frequently-asked-questions }

### Может ли AgenticOS заменить Wonderful? { #is-agenticos-an-alternative-to-wonderful }

Для организаций, которые хотят владеть платформой, — да. AgenticOS открыт и
работает на вашей инфраструктуре, а Vstorm может помочь с внедрением. Wonderful
поставляет закрытую платформу со своими командами внедрения.

### Можно ли развернуть AgenticOS на своих серверах? { #can-agenticos-be-deployed-on-premises }

Да. Он работает с Docker Compose на вашем собственном хосте. С локальной моделью
весь путь может оставаться в вашей сети.

### Поддерживает ли AgenticOS голосовых агентов и агентов в WhatsApp? { #does-agenticos-support-voice-or-whatsapp-agents }

Голос — отчасти: начиная с 1.10.0 участник или посетитель может
[позвонить агенту](../voice.md) из веб-чата, виджета для встраивания или
размещённой страницы, а голосовые заметки, отправленные боту канала,
расшифровываются. Телефонной линии, канала WhatsApp и SMS пока нет.

### Что будет, если мы прекратим работать с Vstorm? { #what-happens-if-we-stop-working-with-vstorm }

Экземпляр продолжит работать. Исходный код под Apache-2.0, спецификации
экспортируются в YAML, а данные лежат в хранилищах, которые запускаете вы: Postgres,
а также тома для медиафайлов и рабочих пространств. Им сможет управлять другая
команда.
