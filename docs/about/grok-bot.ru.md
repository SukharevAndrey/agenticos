# AgenticOS vs Grok Bot { #agenticos-vs-grok-bot }

Источники проверены 2 ноября 2026 года. Базовая версия AgenticOS: v1.35.0. Только документация вендора; учётная запись Grok Bot не тестировалась.

Grok Bot — управляемый сервис ИИ-коллег от xAI. Его текущая документация описывает постоянные облачные компьютеры, подключённые приложения, автоматизации, согласования и корпоративное администрирование. Старые утверждения об отсутствии журнала аудита устарели: журналы аудита и экспорт в OpenTelemetry описаны как доступные только в Enterprise.

## Коротко { #at-a-glance }

| Область | Grok Bot | AgenticOS |
| --- | --- | --- |
| Хостинг | Облако вендора | Ваша инфраструктура |
| Модели | Сервис вендора; проверьте текущий тариф | Провайдеры моделей, выбранные оператором |
| Управление для команды | Журналы аудита, SCIM и список разрешённых MCP-серверов описаны для Enterprise | Роли, бюджеты, согласования и аудит входят в программное обеспечение под Apache-2.0 |
| Компьютер | Общий для ботов пользователя; изоляции между ботами нет | Настроенные песочницы диалога и проекта; сохранённые входы в браузере для каждого человека |
| Цена | Публичные индивидуальные тарифы — $30, $100 и $200 в месяц; действуют условия на включённое недельное использование и дополнительное использование | Без платы за лицензию; инфраструктура и использование моделей оплачиваются отдельно |

## Когда выбрать что { #when-to-choose-each }

Выберите Grok Bot, если хотите управляемых ИИ-коллег без эксплуатации платформы. Выберите AgenticOS, если важно владеть развёртыванием, выбором моделей и общей настройкой агентов. Сравните точные политики согласования и разрешения на инструменты, которые нужны вашей задаче; одна документация не доказывает, что любая из систем предотвращает все небезопасные действия.
