# AgenticOS vs OpenCode { #agenticos-vs-opencode }

OpenCode — агент для работы с кодом с открытым исходным кодом под лицензией MIT.
Он работает в терминале, приложении для компьютера или IDE и подключается к более
чем 75 провайдерам моделей. Это сильный выбор для разработчика, которому нужен
свой агент в своём репозитории. AgenticOS тоже открыт и создан для другой задачи:
множество агентов, множество пользователей, один управляемый экземпляр.

Страницу ведёт команда AgenticOS. Источники проверены 21 октября 2026 года.
Базовая версия AgenticOS: v1.10.0. Охват OpenCode: его документация на opencode.ai,
включая страницы консоли OpenCode 2 в разделе `/v2/`, и репозиторий
`anomalyco/opencode` версии v1.19.3, линия 1.x; тестируемого корпоративного
развёртывания нет.

## Коротко { #at-a-glance }

| Область | OpenCode | AgenticOS |
| --- | --- | --- |
| Для кого | Разработчик, в репозитории | Организация: бизнес-команды, конечные пользователи и инженеры |
| Где работает | Машина разработчика; `opencode serve` для локального HTTP-сервера | Общий сервис на вашей инфраструктуре |
| Исходный код | MIT | Apache-2.0 |
| Модели | Более 75 провайдеров через Models.dev, включая локальные | 28 провайдеров, включая локальные |
| Пользователи и доступ | Один пользователь; в рабочих пространствах консоли есть владельцы, администраторы и участники | Организации, шесть ролей, 33 разрешения, выданные доступы на ресурсы |
| Согласования | `allow`, `ask` или `deny` для каждого инструмента, ответ за клавиатурой | Человек с `approvals:decide` из общей очереди |
| Контроль расходов | Месячные бюджеты для рабочего пространства консоли и каждого участника | Бюджет на агента и на организацию, проверяется перед каждым запросом к модели |
| Аудит | Не описан | Журнал аудита с защитой от подмены |
| Цена | Бесплатно; необязательные кредиты консоли с оплатой по факту, Go за $10 или Go Plus за $40 в месяц; Enterprise за место | Без платы за лицензию; использование моделей и инфраструктура |

## Где AgenticOS идёт дальше { #where-agenticos-goes-further }

### Создан для многих людей, а не для одного { #built-for-many-people-not-one }

OpenCode хранит ключи провайдеров в файле на машине разработчика, и в инструменте
с открытым исходным кодом нет модели пользователей и ролей. В AgenticOS есть
[организации](../concepts.md#organizations),
[роли и выданные доступы](../permissions.md#layer-3-visibility-and-grants) и
[вход через каталог](../directory.md#signing-in-with-a-directory-account). Ключи
лежат в [хранилище секретов, запечатанном для каждой организации](../secrets.md#envelope-encryption),
и ни один эндпоинт их не возвращает.

### Агенты, которые обслуживают конечных пользователей { #agents-that-serve-end-users }

Способы запуска OpenCode — для разработчика: TUI, приложение для компьютера, IDE
и локальный сервер. Агент AgenticOS отвечает людям, которые ничего не
устанавливают: через [виджет для встраивания](../channels.md#the-website-widget),
[размещённую страницу](../channels.md#a-hosted-page),
[Slack, Telegram или Mattermost](../channels.md#slack) или
[HTTP API](../channels.md#the-public-api).

### Управление, записанное на сервере { #governance-recorded-on-the-server }

Разрешения OpenCode защищают машину разработчика. AgenticOS записывает каждый
запуск с его версией, способом запуска, стоимостью и статусом в
[историю запусков](../governance.md#what-run-history-shows).
[Бюджеты](../governance.md#enforcement-is-before-the-request) останавливают агента
перед следующим запросом к модели, а [журнал аудита](../governance.md#audit)
записывает, кто что изменил.

### Знания за пределами репозитория { #knowledge-beyond-the-repository }

OpenCode читает репозиторий и то, что возвращают MCP-серверы. AgenticOS хранит
документы компании в [коллекциях](../file-processing.md#rag-document-ingestion) с
разбором для каждой коллекции и синхронизацией из Drive, S3, SharePoint, сайтов и
git.

## Когда OpenCode — подходящий инструмент { #when-opencode-is-the-right-tool }

- Разработчику нужен агент для работы с кодом с открытым исходным кодом и
  свободным выбором провайдера.
- Работа идёт в репозитории, и решает человек за клавиатурой.
- Вы хотите, чтобы агент работал целиком на машине самого разработчика.

## Используйте их вместе { #use-them-together }

Разработчик может работать в OpenCode с любой моделью, чтобы написать новую
[возможность](../howto/add-capability.md) для AgenticOS. После слияния
бизнес-команды включают её в своих агентах.

## Попробуйте на одной задаче { #try-it-on-one-task }

## Частые вопросы { #frequently-asked-questions }

### Может ли AgenticOS заменить OpenCode? { #is-agenticos-an-alternative-to-opencode }

Для работы с кодом в репозитории — нет. OpenCode — агент для работы с кодом,
рассчитанный на одного разработчика. AgenticOS — платформа для множества агентов и множества
пользователей, с ролями, бюджетами и журналами аудита.

### У OpenCode и AgenticOS открытый исходный код? { #are-opencode-and-agenticos-both-open-source }

Да. OpenCode — MIT, AgenticOS — Apache-2.0, и оба могут работать с локальными
моделями.

### Можно ли открыть доступ к агентам AgenticOS людям, которые не пишут код? { #can-agenticos-agents-be-shared-with-people-who-do-not-code }

Да. Они отвечают через виджет для встраивания, размещённую страницу, Slack,
Telegram, Mattermost или HTTP API, и ничего не нужно устанавливать.

### Может ли OpenCode помочь в создании возможностей AgenticOS? { #can-opencode-help-build-agenticos-capabilities }

Да. Возможность — это типизированный Python в репозитории, и OpenCode может
помочь написать и протестировать её с любой моделью.
