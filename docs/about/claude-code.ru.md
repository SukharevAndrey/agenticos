# AgenticOS vs Claude Code { #agenticos-vs-claude-code }

Claude Code — агентный инструмент Anthropic для работы с кодом. Он читает
репозиторий, правит файлы, выполняет команды и работает в терминале, IDE,
приложении для компьютера, вебе и CI. Он создан для разработчиков, которые
работают с кодом. AgenticOS создан для агентов, которыми пользуются все
остальные: агент по кадровым политикам, виджет поддержки, бот в Slack для отдела
продаж. Бизнес-команды настраивают их в браузере, а платформа ими управляет.

Большинству инженерных команд понадобится и то, и другое. Claude Code пишет и
проверяет код. AgenticOS публикует агентов, которых этот код делает возможными,
управляет ими и учитывает их расходы.

Страницу ведёт команда AgenticOS. Источники проверены 21 октября 2026 года.
Базовая версия AgenticOS: v1.10.0. Охват Claude Code: документация Anthropic на
code.claude.com, страницы тарифов и публичный репозиторий; проверенного
корпоративного развёртывания нет.

## Коротко { #at-a-glance }

| Область | Claude Code | AgenticOS |
| --- | --- | --- |
| Для кого | Разработчики | Бизнес-команды, которые настраивают агентов, и инженеры, которые их расширяют |
| С чем работает | Репозиторий кода и командная оболочка | Документы, инструменты и системы компании — через возможности и MCP |
| Где работает | Машины разработчиков; облачные сеансы на инфраструктуре Anthropic или на вашей | Ваша инфраструктура, как общий сервис |
| Исходный код | Проприетарный: «All rights reserved» | Apache-2.0 |
| Модели | Только Claude — через Anthropic, Amazon Bedrock, Claude Platform on AWS, Agent Platform в Google Cloud (ранее Vertex AI) или Microsoft Foundry | 28 провайдеров, включая Claude |
| Конечные пользователи | Разработчик за клавиатурой | Сотрудники, клиенты и системы — через восемь способов доступа |
| Согласования | Разработчик или классификатор в автоматическом режиме | Человек с `approvals:decide` из общей очереди |
| Контроль расходов | Лимит тарифа, кредиты использования с ограничением расходов или оплата по API; `--max-budget-usd` на запуск в неинтерактивном режиме (print) | Месячный бюджет на каждого агента и на каждую организацию |
| Цена | Входит в Pro, Max, Team и Enterprise; Anthropic называет 150–250 $ на разработчика в месяц при оплате по API | Без платы за лицензию; использование моделей и инфраструктура |

## Где AgenticOS идёт дальше { #where-agenticos-goes-further }

### Агент для тех, кто никогда не открывает терминал { #an-agent-for-people-who-never-open-a-terminal }

В Claude Code нет конструктора для бизнес-пользователей и нет процесса
публикации для не-разработчиков. Его функция Channels в предварительной версии
передаёт события в собственный запущенный сеанс разработчика; она не публикует
агента для других людей. В AgenticOS владелец из бизнеса пишет инструкции,
включает [возможности](../reference/capabilities.md), привязывает коллекцию
знаний и [публикует версию](../concepts.md#version). После этого тот же агент
отвечает в [веб-чате, виджете, Slack, Telegram, Mattermost и через
API](../channels.md).

### Управление, которое живёт на сервере { #governance-that-sits-on-the-server }

Anthropic говорит, что настройки Claude Code, управляемые с сервера, — «клиентский
механизм контроля, а не граница безопасности», и что пользователь, который
направит инструмент к другому провайдеру, эти настройки обойдёт. Когда нужно
более строгое принуждение, Anthropic рекомендует доставку через MDM.

В AgenticOS каждое правило живёт на сервере: [разрешения](../permissions.md),
[бюджеты](../governance.md#enforcement-is-before-the-request),
[согласования](../governance.md#approvals) и
[журнал аудита](../governance.md#audit). Агент не может добраться до отключённой
возможности, что бы ни говорили его инструкции.

### Много провайдеров, один переключатель { #many-providers-one-switch }

Claude Code работает на моделях Claude. AgenticOS позволяет каждому агенту
использовать модель, которая подходит задаче и бюджету: передовую модель для
анализа, подешевле для сортировки, [локальную](../models.md#self-hosted) для
чувствительных данных. [Профиль модели](../models.md#a-model-profile) переводит
всех агентов, которые его используют, одним изменением.

### Знания компании, а не только репозиторий { #company-knowledge-not-only-the-repository }

Контекст Claude Code берётся из репозитория, файлов CLAUDE.md, навыков и
MCP-серверов. AgenticOS добавляет управляемые
[коллекции документов](../file-processing.md#rag-document-ingestion) с
синхронизацией из Drive, S3, SharePoint, с сайтов и из git,
[навыки](../skills.md) и [файлы контекста](../context.md), общие для нескольких
агентов.

## Когда Claude Code — подходящий инструмент { #when-claude-code-is-the-right-tool }

- Работа — это код: функции, исправления, проверки, рефакторинги и задачи CI.
- Его режимы разрешений, песочница уровня ОС, хуки и субагенты — именно то, что
  нужно за столом разработчика.
- Решения о том, что может делать агент, принимает один разработчик за раз.

## Используйте их вместе { #use-them-together }

AgenticOS расширяется типизированным Python, и Claude Code хорошо его пишет.
[Возможность](../howto/add-capability.md), которую Claude Code помог инженеру
написать, протестировать и проверить, после слияния становится переключателем в
Конструкторе у всех. В репозитории есть навыки и правила для агентов именно под
эту работу.

Спецификация также
[экспортируется в YAML](../features.md#exportable-into-your-own-repository),
поэтому Claude Code может проверить изменение агента в пул-реквесте, как любой
другой файл.

Они сходятся и во время выполнения. Агент с возможностью
[агент для работы с кодом](../reference/capabilities.md#coding-agent) отдаёт
работу с кодом в Claude Code в его собственной песочнице, и каждый шаг
появляется в чате по ходу дела, так что бизнес-пользователь может попросить
страницу или скрипт, не открывая терминал. В обратную сторону:
[AgenticOS — это MCP-сервер](../mcp.md#agenticos-as-an-mcp-server), поэтому
Claude Code подключается после входа и может перечислять и запускать агентов
компании, читать их запуски и искать в их базах знаний.

## Частые вопросы { #frequently-asked-questions }

### AgenticOS — альтернатива Claude Code? { #is-agenticos-an-alternative-to-claude-code }

Нет, они решают разные задачи. Claude Code — агент для работы с кодом для
разработчиков. AgenticOS — платформа для агентов, которыми пользуется остальная
компания. Многие команды используют оба, и агент AgenticOS может отдать работу с
кодом в Claude Code.

### Может ли Claude Code помочь что-то сделать на AgenticOS? { #can-claude-code-help-build-on-agenticos }

Да. AgenticOS расширяется типизированным Python, и возможность, написанная с
помощью Claude Code, после слияния становится доступна в конструкторе любого
агента. В репозитории есть навыки и правила для агентов под эту работу.

### Могут ли агенты AgenticOS использовать модели Claude? { #can-agenticos-agents-use-claude-models }

Да, через API Anthropic или Amazon Bedrock — два из 28 провайдеров, которые
поддерживает AgenticOS.

### Claude Code — это открытый исходный код? { #is-claude-code-open-source }

Нет. В его репозитории указано «All rights reserved», а использование регулируется
коммерческими условиями Anthropic. AgenticOS распространяется под Apache-2.0.
