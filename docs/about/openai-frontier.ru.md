# AgenticOS vs OpenAI Frontier { #agenticos-vs-openai-frontier }

OpenAI Frontier — корпоративная платформа для создания «ИИ-коллег» и управления ими: агентов, которые делят контекст из CRM и хранилищ данных компании, хранят память, проходят оценку и имеют собственные разрешения. Она работает локально, в облаке компании или в облаке OpenAI. AgenticOS отвечает на ту же потребность — много управляемых агентов для компании — как открытый исходный код, который вы запускаете сами, с любой моделью.

Если вы сделали ставку на OpenAI и хотите, чтобы платформу предоставила она, Frontier — ответ самого вендора. Если вы хотите владеть платформой, читать её код и выбирать модели, для этого и создан AgenticOS.

Страницу ведёт команда AgenticOS. Источники проверены 14 октября 2026 года. Базовая версия AgenticOS: v1.10.0. Что проверено у Frontier: анонс OpenAI от 5 февраля 2026 года по сообщениям прессы; цены не публиковались, и учётная запись не тестировалась.

## Коротко { #at-a-glance }

| Область | OpenAI Frontier | AgenticOS |
| --- | --- | --- |
| Что вы получаете | Управляемую платформу для корпоративных ИИ-коллег | Слой на собственной инфраструктуре для агентов компании |
| Где работает | Локально, в вашем облаке или в облаке OpenAI | Ваша инфраструктура, с Docker Compose |
| Исходный код | Проприетарный | Apache-2.0 |
| Модели | OpenAI | 28 провайдеров, включая локальные модели |
| Контекст компании | Подключён к CRM и хранилищам данных | Базы знаний, синхронизируемые из Drive, S3, SharePoint, OneDrive, сайтов и git; более 4700 MCP-серверов |
| Управление | Разрешения для каждого агента, оценки, панели | Роли и выданные доступы на отдельные ресурсы, согласования, бюджеты, проверяемые перед каждым запросом к модели, журнал аудита с защитой от подмены |
| Цена | Не опубликованы | Без платы за лицензию; вы платите провайдерам моделей и за инфраструктуру |

## Где AgenticOS идёт дальше { #where-agenticos-goes-further }

### Открытый исходный код, поэтому платформа ваша { #open-source-so-the-platform-is-yours }

Frontier — продукт, который вы лицензируете. AgenticOS распространяется по Apache-2.0: вы можете прочитать каждую строку, изменить код, [расширить его на Python](../howto/add-capability.md) и запускать платформу для других. Спецификация агента [экспортируется в YAML](../features.md#exportable-into-your-own-repository) в ваш собственный репозиторий.

### Любая модель { #any-model }

Frontier построен вокруг моделей OpenAI. Агент AgenticOS использует [профиль модели](../models.md#a-model-profile) поверх 28 провайдеров, с резервными моделями, включая модели на вашем собственном оборудовании.

### Управление без звонка в отдел продаж { #governance-without-a-sales-call }

[Бюджеты](../governance.md#enforcement-is-before-the-request), [согласования](../governance.md#approvals), [роли и выданные доступы](../permissions.md#the-built-in-roles) и [журнал аудита](../governance.md#audit) есть в каждом экземпляре AgenticOS, с документацией и без тарифа Enterprise.

## Когда Frontier достаточно { #when-frontier-is-enough }

- Вы стандартизируете всё на OpenAI и хотите, чтобы она эксплуатировала платформу за вас.
- Его коннекторы к вашей CRM и хранилищам данных покрывают ваши данные.
- Набор для оценок важен уже сегодня: у AgenticOS есть оценки ответов и история запусков, но пока нет стенда для оценок.

## Частые вопросы { #frequently-asked-questions }

### AgenticOS — альтернатива OpenAI Frontier с открытым исходным кодом? { #is-agenticos-an-open-source-alternative-to-openai-frontier }

Да. Оба дают компании много агентов с разрешениями и общим контекстом. AgenticOS распространяется по Apache-2.0, работает на вашей инфраструктуре и совместим с любым из 28 провайдеров моделей.

### Есть ли у AgenticOS оценки, как в Frontier? { #does-agenticos-have-evaluations-like-frontier }

Пока нет. AgenticOS записывает каждый запуск с его шагами, стоимостью и оценками ответов; стенд для оценок есть в плане развития.
