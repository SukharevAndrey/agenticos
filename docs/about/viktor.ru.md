# AgenticOS vs Viktor { #agenticos-vs-viktor }

Viktor продаёт одного ИИ-коллегу на рабочее пространство Slack или Microsoft
Teams: он работает в облаке Viktor, а оплата идёт кредитами. AgenticOS даёт
столько агентов, сколько нужно, и у каждого свои инструкции, модель, инструменты,
знания, бюджет и правила доступа, на инфраструктуре, которую вы контролируете.

Если вам нужен один полезный коллега в чате уже к вечеру, Viktor быстро
пробуется. Если вы хотите сами решать, что может делать каждый агент, сколько это
стоит и где лежат данные, AgenticOS даёт такой контроль.

Страницу ведёт команда AgenticOS. Источники проверены 21 октября 2026 года.
Базовая версия AgenticOS: v1.10.0. Охват Viktor: его открытые страницы продукта, цен,
безопасности и корпоративных решений, а также список изменений; тестируемой
учётной записи и согласованного договора нет.

## Где AgenticOS идёт дальше { #where-agenticos-goes-further }

### Много агентов, у каждого своя работа { #many-agents-each-with-a-job }

Viktor — один ИИ-коллега, которым пользуется всё рабочее пространство. В AgenticOS
каждый агент создан для своей задачи: агент по кадровой политике, помощник по
продажам или агент сортировки обращений в поддержку. У каждого свои инструкции,
[возможности](../reference/capabilities.md), коллекции знаний и бюджет.

Спецификация агента [версионируется при публикации](../concepts.md#version) и
[экспортируется в YAML](../features.md#exportable-into-your-own-repository) в ваш
git-репозиторий. Именованные [окружения](../environments.md#what-an-environment-is)
позволяют проверить версию в staging, прежде чем на неё начнёт отвечать
production.

### Доступ решается для каждого агента и каждого человека { #access-decided-per-agent-and-per-person }

В разделе вопросов на главной странице Viktor (проверено 21 октября 2026 года)
сказано, что все участники команды на плане делят один экземпляр Viktor и один
контекст, а подключённый инструмент можно открыть всей команде или, в рабочих
пространствах Slack, оставить личным. Его страница для предприятий упоминает
ролевой доступ. Спросите, что действует по вашему договору.

В AgenticOS доступ определяется
[каталогом разрешений](../permissions.md#the-built-in-roles), а
[выданные доступы](../permissions.md#layer-3-visibility-and-grants) открывают один
агент, навык или коллекцию человеку или группе. Привязка MCP может использовать
[учётную запись каждого человека](../mcp.md#whose-account-a-binding-speaks-through),
а не один общий вход. Связанный пользователь Slack выполняет запуски
[от своего имени](../channels.md#slack).

### Бюджет на каждого агента, а не только пул кредитов { #a-budget-per-agent-not-only-a-credit-pool }

Viktor выставляет счёт за пул кредитов рабочего пространства и утверждает, что
кредиты соответствуют тому, что берут провайдеры моделей. В AgenticOS кредитов
нет. У каждого агента есть [месячный бюджет](../governance.md#budgets), который
проверяется
[перед каждым запросом к модели](../governance.md#enforcement-is-before-the-request).
Неудачный запуск всё равно записывает свои расходы, а
[оповещение](../governance.md#alerts) сообщает выбранным вами людям, когда агент
достигает своего лимита.

### Ваши данные остаются там, где вы их разместили { #your-data-stays-where-you-put-it }

Viktor размещён в США. Его страницы расходятся в описании размещения в ЕС и
настраиваемых сроков хранения, поэтому подтвердите и то и другое письменно.
AgenticOS хранит диалоги, документы и векторы в
[вашем собственном Postgres](../data-protection.md#where-personal-data-lives).
Сроки [хранения для каждого класса данных](../governance.md#retention) задаёте вы.
С локальной моделью ничего не должно покидать вашу сеть.

### Знания, которые можно проверить { #knowledge-you-can-inspect }

Viktor учится на диалогах и подключённых инструментах. AgenticOS добавляет
управляемые коллекции документов: вы выбираете
[парсер](../file-processing.md#parser-selection-rag) и
[разбиение на фрагменты](../file-processing.md#chunking-configuration) для каждой
коллекции. Синхронизировать можно из Google Drive, S3, SharePoint или OneDrive, с
сайта или из git-репозитория. Синхронизация
[удаляет документы](../howto/configure-sync-sources.md#what-a-sync-removes),
которых больше нет в источнике.

## Когда Viktor достаточно { #when-viktor-is-enough }

- Вам нужен один помощник в Slack или Teams, и не нужно ничего разворачивать.
- Его каталога из более чем 9 800 инструментов и песочницы для кода хватает для
  ваших задач.
- Оплата кредитами и размещение в США вас устраивают.
- Вам уже сегодня нужны Microsoft Teams, телефонная линия или почтовый ящик. У
  AgenticOS пока нет канала Teams, телефонии и электронной почты; его
  [голосовые звонки](../voice.md) работают в браузере.

## Попробуйте один вопрос из справочника { #try-one-handbook-question }

Возьмите [общий образец документа](../howto/first-document-agent.md). Сравните
доступ к источнику, сам ответ, вопрос об отсутствующей политике и обновление
источника. Проверьте, какая учётная запись может получить источник и как доступ
отзывается, когда человек уходит.

Затем запустите в каждом продукте второго агента для другой команды. Проверьте,
видит ли он интеграции и память первой команды. Именно на втором агенте разница
между коллегой для рабочего пространства и платформой агентов проявляется
сильнее всего. Запишите результат по [методике сравнения](comparison.md#a-shared-trial).

## Частые вопросы { #frequently-asked-questions }

### Может ли AgenticOS заменить Viktor? { #is-agenticos-an-alternative-to-viktor }

Да, если вам нужно больше одного общего помощника. AgenticOS запускает множество
агентов, и у каждого свои инструкции, доступ, знания и бюджет, на вашей
собственной инфраструктуре. Viktor быстрее запускается в Slack или Teams и
работает в своём облаке.

### Может ли AgenticOS отвечать в Slack, как Viktor? { #can-agenticos-answer-in-slack-like-viktor }

Да. Опубликованный агент отвечает в Slack, а связанный пользователь выполняет
запуски от своего имени. AgenticOS также отвечает в Telegram, Mattermost, виджете
для встраивания, размещённой странице и через HTTP API. Канала Microsoft Teams у
него пока нет.

### Как соотносятся цены? { #how-does-pricing-compare }

Viktor продаёт кредиты рабочего пространства: Team стоит $100 в месяц за 40 000
кредитов, общих для всего рабочего пространства. У AgenticOS нет платы за лицензию:
вы платите провайдерам моделей напрямую, и у каждого агента свой месячный
бюджет.

### Где хранятся данные? { #where-is-the-data-stored }

Viktor сообщает, что по умолчанию размещён в США, а размещение в ЕС предлагается
на договорах Enterprise: на одной странице оно указано как доступное, на другой —
как запланированное. AgenticOS хранит диалоги, документы и векторы в вашем
собственном Postgres, где бы вы его ни развернули.
