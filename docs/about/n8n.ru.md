# AgenticOS vs n8n { #agenticos-vs-n8n }

n8n сочетает визуальные сценарии, узлы AI Agent и нативных агентов в предварительной версии. У его нативных агентов есть собственные инструкции, инструменты, навыки, знания и расписания. У AgenticOS тоже есть агенты и сценарии; сравните модель работы, лицензию, доступ и контроль расходов для вашей задачи.

Они хорошо сочетаются. n8n перемещает данные между системами по расписанию. AgenticOS запускает агентов, которым нужны владелец, согласующий и лимит расходов.

Страницу ведёт команда AgenticOS. Источники проверены 21 октября 2026 года. Базовая версия AgenticOS: v1.10.0. Что проверено у n8n: его страница цен, документация и лицензия на n8n@2.44.5, а не протестированный облачный тариф и не лицензия Enterprise при самостоятельном размещении.

Утверждения о возможностях AgenticOS обновлены 2 ноября 2026 года по версии v1.35.0. Дата проверки источников вендора выше не изменилась; это не новая проверка цен вендора.

Доступность нативных агентов и настройку знаний при самостоятельном размещении перепроверили по официальной документации n8n 2 ноября 2026 года. Нативные агенты находятся в предварительной версии на облачных и самостоятельно размещённых тарифах начиная с 2.32.3. Это не возобновляет проверку цен выше.

| Лицензия | Sustainable Use License, файлы `.ee` — под n8n Enterprise License | Apache-2.0 |

| Роли | Проекты и роли на платных тарифах; не в Community Edition | Шесть ролей и выданные доступы на отдельные ресурсы в каждом экземпляре |

## Где AgenticOS идёт дальше { #where-agenticos-goes-further }

### Лицензия без мелкого шрифта { #a-licence-without-the-fine-print }

Sustainable Use License от n8n разрешает использование «только для собственных внутренних деловых целей, а также для некоммерческого или личного использования». Возможности в файлах `.ee` требуют платного лицензионного ключа. Страница цен n8n говорит, что ключ лицензии для самостоятельного размещения ежедневно обращается к её серверу лицензий.

AgenticOS распространяется по Apache-2.0. Вы можете запускать его для клиентов, изменять и строить на нём продукт; проверьте [лицензии входящих компонентов](../licenses.md#the-agpl-component) для образа, который поставляете. Свежая установка [не отправляет промпты и документы никуда](../data-protection.md#nothing-leaves-by-default); [диагностика экземпляра](../configuration.md#diagnostics) включена по умолчанию, и её можно отключить.

### Корпоративный контроль без смены тарифа { #enterprise-controls-without-a-plan-upgrade }

В n8n SSO, проекты, окружения, контроль версий в Git и потоковая передача журналов доступны на платных тарифах. Community Edition оставляет сценарии и учётные данные у их владельца. В AgenticOS они входят в открытый продукт:

- [вход через каталог и сопоставление групп](../directory.md#directory-group-mappings)
- [роли и выданные доступы](../permissions.md#layer-3-visibility-and-grants)
- [окружения](../environments.md#what-an-environment-is) и [экспорт в YAML](../features.md#exportable-into-your-own-repository)
- [журнал аудита с защитой от подмены](../governance.md#audit)

### Деньги, а не выполнения { #money-not-executions }

n8n считает выполнения, и один ход агента — это одно выполнение, сколько бы ни потратила модель. Его документация не описывает бюджета ни на токены модели, ни на её стоимость. AgenticOS измеряет стоимость модели по цене из снимка, входящего в поставку. [Бюджет](../governance.md#budgets) каждого агента проверяется [перед каждым запросом к модели](../governance.md#enforcement-is-before-the-request), [порученная работа](../governance.md#delegation-spends-the-parents-budget) засчитывается родителю, а [экран стоимости](../governance.md#what-the-cost-screen-shows) показывает расходы по каждому агенту.

### Агент, которого может изменить владелец из бизнеса { #an-agent-a-business-owner-can-change }

Оба продукта позволяют владельцу настраивать и агентов, и сценарии. Нативные агенты n8n находятся в предварительной версии. Агент AgenticOS меняется, когда владелец правит инструкции и публикует. Настройка может дотянуться только до [возможностей](../reference/capabilities.md), зарегистрированных инженерами, а каждая [версия](../concepts.md#version) остаётся читаемой.

### Знания как управляемая коллекция { #knowledge-as-a-managed-collection }

n8n собирает поиск из узлов: загрузчиков, эмбеддингов и выбранного вами векторного хранилища. Его функция Agents в предварительной версии добавляет управляемую базу знаний, которой при самостоятельном размещении нужна настроенная песочница. AgenticOS хранит [коллекции](../file-processing.md#rag-document-ingestion) в вашем Postgres с выбором парсера, OCR, описанием изображений и [коннекторами синхронизации](../howto/configure-sync-sources.md#what-a-sync-removes), которые удаляют то, что удалено в источнике.

## Когда n8n подходит лучше { #when-n8n-is-the-better-fit }

- Задача — перемещать данные между множеством систем, с ветвлениями, повторами и расписаниями.
- Вам больше нравится именно эта библиотека узлов, интеграции и опыт редактирования сценариев. У AgenticOS тоже есть визуальный конструктор сценариев; доступные узлы и семантика выполнения различаются.
- Вам нужны его каналы проверки, такие как Microsoft Teams, WhatsApp или Gmail, либо его метрики оценки. У AgenticOS пока нет ни того, ни другого.

## Используйте их вместе { #use-them-together }

Сценарий n8n может вызвать агента AgenticOS через [HTTP API](../channels.md#the-public-api) и получить ответ. Бюджет агента проверяется, его согласования по возможностям действуют, а запуск записывается в [историю запусков](../governance.md#what-run-history-shows). [Триггер-вебхук](../triggers.md) AgenticOS может запустить агента, когда n8n отправит ему запрос.

Соберите [общего агента по документам](../howto/first-document-agent.md) в обоих. Дайте каждому лимит расходов в несколько центов и запустите его сверх этого лимита. Затем дайте второй команде собственную копию и проверьте, что видит первая команда. Запишите результат по [методике сравнения](comparison.md#a-shared-trial).

## Частые вопросы { #frequently-asked-questions }

### AgenticOS — альтернатива n8n с открытым исходным кодом? { #is-agenticos-an-open-source-alternative-to-n8n }

Для ИИ-агентов — да. AgenticOS распространяется по Apache-2.0, а n8n использует Sustainable Use License. Для перемещения данных между множеством систем на визуальном холсте лучше подходит n8n, и вместе они работают хорошо.

### У n8n открытый исходный код? { #is-n8n-open-source }

Нет, в смысле OSI. Его Sustainable Use License разрешает внутреннее деловое, некоммерческое и личное использование, а возможности в файлах `.ee` требуют лицензии n8n Enterprise.

### Может ли n8n вызвать агента AgenticOS? { #can-n8n-call-an-agenticos-agent }

Да. Сценарий n8n может вызвать HTTP API AgenticOS и получить ответ. Бюджет агента проверяется, а запуск записывается в историю запусков.

### Как цены n8n соотносятся с AgenticOS? { #how-does-n8n-pricing-compare-with-agenticos }

n8n Cloud начинается с €20 в месяц за 2500 выполнений с оплатой за год и считает каждый ход агента одним выполнением. У AgenticOS нет платы за лицензию, а стоимость модели учитывается в бюджете каждого агента.
