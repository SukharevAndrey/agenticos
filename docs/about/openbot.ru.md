# AgenticOS vs OpenBot { #agenticos-vs-openbot }

Источники проверены 2 ноября 2026 года. Базовая версия возможностей AgenticOS: v1.35.0. Ни учётная запись OpenBot, ни перенос не тестировались.

OpenBot — рабочее пространство ИИ-коллег, работающее в первую очередь локально, на openbot.run, за которым стоит nightly-labs/openbot. Его официальный сайт также описывает серверы для команд и варианты хостинга. Он умеет работать через существующих провайдеров агентов, поэтому «в первую очередь локально» не значит, что каждый вызов модели остаётся на компьютере.

Лицензия репозитория на 2 ноября 2026 года — PolyForm Noncommercial 1.0.0. AgenticOS использует Apache-2.0. Сравните фактические условия лицензии и любые отдельно предложенные коммерческие условия, прежде чем выбирать для бизнес-развёртывания; эти две модели лицензирования различаются.

## Какое рабочее пространство подходит? { #which-workspace-fits }

Выберите OpenBot ради его настольного рабочего пространства и интеграций с провайдерами, если они подходят вашей работе. Выберите AgenticOS ради платформы для компании на собственной инфраструктуре с общими проектами, версионируемыми агентами, сценариями, виртуальными таблицами, бюджетами и политиками согласования. Это сравнение по документации, а не протестированный перенос или замер.

## Начните с одной задачи { #move-one-task-first }

Воссоздайте одну небольшую задачу в AgenticOS: скопируйте инструкции, которые можно использовать повторно, добавьте нужные знания и навыки, выберите модель, заново подключите инструменты через хранилище секретов и настройте бюджеты и согласования. Проверьте чтение и убедитесь, что запись отклоняется, ещё до публикации. Это ручная процедура; AgenticOS не обещает ни импортёра из OpenBot, ни переносимых сеансов входа, ни одинаковой памяти.
