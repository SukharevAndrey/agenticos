# Глоссарий { #glossary }

Слова, которые использует консоль, что каждое из них значит и как та же вещь
называется в API, в спецификации и в YAML, который экспортирует агент. Консоль,
обучающий тур, Архитектор и эти страницы используют эти имена; API и спецификация
сохраняют свои, поэтому скрипт, написанный под них, не сломается из-за
переименования в консоли.

## Что вы создаёте { #what-you-build }

| В консоли | Что это | В API и спецификации |
|---|---|---|
| Агент | Ассистент со своими инструкциями, моделью, знаниями и инструментами | `agent` |
| Черновик | Неопубликованные изменения агента; за пределами Конструктора их не видит никто | `draft_spec` |
| Опубликовать | Зафиксировать черновик как пронумерованную версию, на которой работают все способы доступа | `POST /agents/{id}/publish` |
| Версия | Одно опубликованное состояние агента, сохранённое и сравнимое | `agent_version` |
| Панель проверки | Чат рядом с Конструктором, который отвечает как черновик или как любая версия | `is_test` в её запусках |
| Инструкции | То, что агенту сообщают перед каждым диалогом | `instructions` |
| Переменные | `{{name}}` в инструкциях, подставляются, когда начинается запуск | `variables` |
| Первые сообщения | То, что пустой чат предлагает тому, кто открыл агента, — каждое в один клик | `starters` |
| Возможность | То, что агент может делать; включается в Конструкторе | `capabilities[]` |
| Навык | Ноу-хау, записанное один раз и читаемое любым агентом, которому оно нужно | `skill` |
| Версия навыка | Одно сохранённое состояние навыка, которое потом не меняется; **Восстановить** (Restore) возвращает более раннее состояние новой версией | `skill_version` |
| Основная версия | Главная версия навыка, от которой идут ответвления; агент на основной версии читает её новейшую версию | `state: main` |
| Закреплено | Агент, который остаётся на одной основной версии навыка, пока кто-нибудь не переведёт его | `state: pinned` |
| Ответвление | Именованное ответвление навыка, начатое с основной версии, со своими версиями для части агентов | `skill_fork`, `state: fork` |
| Отстаёт от основной | На сколько основных версий отстаёт агент с закреплённой версией или ответвление | `behind_main` |
| Обновить до основной версии | Перевести агента с закреплённой версией или ответвление на новейшую основную версию; только по запросу и после проверки | `/skills/behind-main` |
| Файл контекста | Постоянные знания, которые у агента есть всегда, например глоссарий или политика | `context` |
| База знаний | Документы, которые агент ищет и на которые ссылается | `collection` |
| Пробел в знаниях | Тема из вопросов, на которые база знаний не смогла ответить, сгруппированных по смыслу; в «Улучшении» такие темы считаются как **Нет в базе знаний** (Missing from the knowledge base) | `knowledge_gap_topic` |
| Приложение | Страница, которую публикует агент, например отчёт или небольшая панель с показателями | `artifact` |
| Архитектор | Ассистент в углу каждой страницы, который может строить агентов вместе с вами | `platform-assistant` |
| Системный агент | Агент, которого платформа запускает сама: судья, составитель пробелов или классификатор пробелов; такие агенты перечислены отдельно в разделе **Системные агенты** (System agents) | `kind` не `agent` |
| Помощник по редактированию | Предлагает изменения агента, навыка или файла контекста по ответам с отрицательной оценкой; каждое решает человек | `authoring` |
| Предложение | Одно предложенное изменение черновика, которое принимают, правят или скрывают по отдельности | `spec_proposal_hunk` |
| Изменение настройки | Предложение изменить одну часть конфигурации агента, например модель или возможность | `spec_field` hunk |
| Изменение файла контекста | Новое содержимое, которое ассистент предложил для файла контекста; применяется или отклоняется на странице «Контекст» | `context_proposal` |
| AgenticOS | Универсальный агент, с которого новая организация начинает в «Чате», и то, с чего начинается новый агент | `general/agenticos` |

## Где это работает { #where-it-runs }

| В консоли | Что это | В API и спецификации |
|---|---|---|
| Чат | Веб-диалог с агентом | `conversation` |
| Канал | Slack, Telegram, Mattermost, Discord или Matrix — там, где люди обращаются к агенту | `channel_bot` |
| Автоматизация | Агент, работающий сам — по расписанию или по событию | `trigger` |
| Набор проверок | Набор данных, по которому проверяют агента; запускается по расписанию, при публикации или переводе в окружение либо после изменения | `eval_suite` |
| Запуск | Один ответ агента со стоимостью и шагами | `agent_run` |
| Окружение | Именованный этап, например production, указывающий на одну версию | `environment` |
| Обязательная проверка | Набор проверок, который окружение требует пройти на версии, прежде чем её принять | `guard_suite_ids` |
| Обход проверок | Перевод в окружение в обход обязательных проверок, которые не прошли, с указанием причины | `override_reason` |
| MCP-сервер | Внешний сервер инструментов, который вызывают агенты, подключённый один раз | `mcp_connection` |
| Внешний агент | Агент другого поставщика, доступный по A2A, которому агенты поручают работу | `external_agent` |
| Agent2Agent (A2A) | Протокол, с помощью которого агенты других систем отправляют агенту задачи | `a2a_enabled` |
| Песочница | Изолированный компьютер, где агент пишет файлы и выполняет код | `sandbox` |
| Документы | Файлы, которые агенты хранят для человека — приложенные или написанные, в своих песочницах | `workspace` |

## Кто решает { #who-decides }

| В консоли | Что это | В API и спецификации |
|---|---|---|
| Организация | Компания или команда, которой принадлежит всё | `organization` |
| Группа | Отдел или команда, которым открывают доступ к агентам, навыкам и знаниям | `group` |
| Руководитель | Участник группы, который управляет тем, кто ещё в ней состоит | `is_lead` |
| Согласование | Вызов инструмента, ожидающий разрешения человека | `approval` |
| Бюджет | Лимит расходов, который останавливает запуски, когда он достигнут | `budget` |
| Защитные проверки | Проверки, которые вырезают или блокируют то, что проходит через запуск | `guardrails` |
| Секреты | Где хранятся ключи и токены: зашифрованы и больше не показываются | `secret` |
| Помощники оценивания | Заданные кодом конвейеры оценивания, генерации и улучшения, настроенные для набора данных | `scoring.judge`, `helper_settings` |

## Как это проверяется { #how-it-is-tested }

| В консоли | Что это | В API и спецификации |
|---|---|---|
| Набор данных | Тестовые кейсы с версиями, по которым проверяют ответы агента; в «Улучшении» — **Тестовые вопросы** (Test questions) | `dataset` |
| Кейс | Один вопрос и то, по чему проверяется хороший ответ; в «Улучшении» — тестовый вопрос | `dataset_case` |
| Оценивание | Как оцениваются ответы набора данных: проверки, эталонный ответ и судья | `scoring` |
| Критерий | То, по чему судья оценивает каждый ответ, — по шкале или как «да/нет» | `criteria[]` |
| Правило | Проверка, которую ответ проходит или не проходит без модели: фраза, шаблон или длина; такие правила перечислены в разделе **Проверки** (Checks) | `checks[]` |
| Судья | Агент, который оценивает ответы в запусках оценки; запускает его только платформа | `kind: judge` |
| Модель для оценки | Модель, на которой оценивают новые судьи; выбирается один раз для организации | `grading_model_profile_id` |
| Оценка | Агент отвечает на каждый кейс набора данных; ответы оцениваются и сравниваются с предыдущей версией | `eval_run` |
| Подтверждённая регрессия | Кейс, который проходил раньше и при каждом повторе снова не проходит; «Улучшение» говорит о нём **Теперь сломано** (Newly broken) | `flip: regression`, `confirmed: true` |
| Подтверждённое исправление | Кейс, который раньше не проходил и при каждом повторе снова проходит; «Улучшение» говорит **Теперь исправлено** (Newly fixed) | `flip: fixed`, `confirmed: true` |
| Не подтверждено | Кейс, который изменился один раз, но при повторе изменился иначе, поэтому не считается ни тем, ни другим; «Улучшение» показывает его как **Пока не подтверждено** (Not confirmed yet) | `confirmed: false` |
| Шум | Ответы, оценённые иначе при повторном вопросе, когда ничего не менялось; результат, который можно объяснить шумом, остаётся в пределах шума, и **Задавать каждый вопрос дважды** (Ask each question twice) это измеряет | `measurement_noise`, `purpose: stability` |
| Проверка | Оценки, ожидающие, когда человек подтвердит их или пересмотрит | `review_state` |
| Генератор кейсов | Системный агент, который пишет черновики кейсов по агенту, его знаниям, реальным чатам и проверке отказа | `kind: generator` |
| Предложенный кейс | Черновой кейс, который ждёт под меткой **Сгенерирован** (Generated), пока человек его не примет или не скроет | `case_proposal` |
| Проверка отказа | Кейсы, проверяющие, что агент отказывает в том, в чём обязан | тег `red-team` |

## Как это улучшается { #how-it-is-improved }

| В консоли | Что это | В API и спецификации |
|---|---|---|
| Улучшение | Сеанс, который читает, что пошло не так с агентом, пишет изменения и проверяет их, ожидая человека между шагами; сам он никогда не публикует | `improvement` |
| Понимание | Первый шаг: раскладывает ответы с отзывами на то, что агент может исправить, и то, чего не хватает в базе знаний | `stage: analyzing`, `stage: classifying` |
| Изменения | Шаг, на котором помощник пишет изменения попытки, а вы выбираете, какие проверять | `stage: proposing`, `stage: filtering` |
| Проверка | Шаг, на котором сегодняшняя версия и изменённая отвечают на одни и те же вопросы и обе оцениваются; **Открыть полную проверку** (Open the full check) открывает её запуск оценки | `stage: evaluating`, `stage: judging` |
| Результат | К чему пришёл сеанс: какая попытка сделала агента лучше (или что ни одна этого не сделала) и что можно сделать дальше | `status: ready`, `status: stopped` |
| Принятие | Последний шаг: **Опубликовать версию N** (Publish version N) или **Оставить черновиком** (Keep as draft); любой из них завершает сеанс | `POST /{run_id}/finish` |
| Попытка | Одна проба в сеансе: изменения написаны, затем проверены на собственных вопросах; не больше трёх за сеанс | `improvement_iteration` |
| Помощник, который пишет изменения | Агент, который читает отзывы и пишет изменения каждой попытки; помощник по редактированию, если не выбран другой | `improver_agent_id` |
| Оставлены для контроля результата | Тестовые вопросы, которые попытка скрывает от помощника, чтобы только они решали её результат | `improvement_partition: holdout` |
| Помогают написать изменения | Тестовые вопросы, которые помощник читает, пока пишет изменения попытки; они никогда не решают её результат | `improvement_partition: train` |
| Попробовать снова | Начинает ещё одну попытку из результата, с необязательным полем **Заметка для помощника** (Note for the helper); она пишет новые изменения и останавливается на шаге «Изменения» | `/{run_id}/continue` с `note` |
| Лимит расходов | Сколько может потратить один сеанс всего, включая анализ и каждую попытку; стоимость каждого шага рассчитывается до его запуска | `budget_usd` |
| Автоматическая проверка | **Проверять эти вопросы автоматически при каждом изменении** (Check these questions automatically on every change): при принятии — набор проверок, который задаёт вопросы сеанса перед каждой публикацией и не допускает ни одной подтверждённой регрессии | `automatic_check` |
| Улучшить навык | Сеанс, который улучшает основную версию навыка или одно из его ответвлений и проверяет изменение на каждом агенте, который эту версию читает | `/skills/{id}/improvements` |
| Проверка навыка | Изменение навыка, запущенное на каждом агенте, который читает эту основную версию или ответвление; лучше, когда ни у одного агента нет подтверждённой регрессии и хотя бы один стал лучше | `skill_check` |
| Неизвестно | Агент, на котором проверку навыка не удалось запустить; указывается вместе с причиной, и человек подтверждает это перед применением | `state: unknown` |
