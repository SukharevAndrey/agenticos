# Каталог разрешений { #the-permission-catalog }

Всё, что участнику можно разрешить делать, насколько широко действует каждое разрешение и
как из них составлены встроенные роли.

Объяснение и то, как сочетаются четыре слоя, — в разделе [Разрешения](../permissions.md);
эта страница — сгенерированный справочник.

::: app.core.permissions

## Как определяется доступ к одной строке { #resolving-access-to-one-row }

Не сгенерировано. `app/services/` — неявный пакет пространства имён: в нём нет
`__init__.py`, поэтому статический сборщик не может в него зайти; а справочная страница,
которая молча пропустила бы половину символов, была бы хуже страницы, которая говорит,
где искать.

Формула и каждый отказ, который она выносит, описаны в разделе
[Разрешения](../permissions.md#how-the-layers-combine). Исходник —
[`app/services/access.py`](https://github.com/vstorm-co/agenticos/blob/main/backend/app/services/access.py),
где обоснование изложено в docstring-строках.
