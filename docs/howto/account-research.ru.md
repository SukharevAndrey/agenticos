# Составьте справку о компании перед звонком { #brief-yourself-on-a-company-before-a-call }

Создайте агента, который исследует организацию и пишет справку на одну страницу
перед звонком с ней: чем она занимается, свежие новости, текущее руководство и что
подтвердить не удалось. В качестве примера взят известный фонд с открытым исходным
кодом, поэтому справку можно сверить с источниками, которые откроет любой. Это
процедура для выполнения, с одним записанным запуском как ориентиром.

## Что понадобится { #what-you-need }

- [Работающий экземпляр](../install.md) с профилем модели.
- Веб-поиск: метод по умолчанию — DuckDuckGo, учётная запись и ключ не нужны.
- Ни коллекции знаний, ни песочницы, ни подключения MCP не нужно.

## Создайте агента { #build-the-agent }

1. Создайте агента в **Агенты → Новый агент** (Agents → New agent) и выберите
   профиль модели.
2. На вкладке **Инструменты** (Toolbox) включите **Поиск в интернете** (Web
   search) с методом DuckDuckGo и **Чтение веб-страниц** (Read web pages).
3. Задайте бюджет и лимит шагов для пробы. В записанном запуске было 20 шагов и
   около 0,26 USD.
4. Задайте инструкции ниже, затем нажмите **Опубликовать** (Publish).

```text
You write a one-page brief on an organization before a call with them.
Research it with web search and web fetch before writing anything.

Rules:

- Every fact in the brief carries the source URL it came from, next to the
  fact, not collected in a list at the end.
- Next to each fact, name the date: either the date the source page itself
  states (an article date, a filing date) or, when the source carries none,
  the date you fetched it, marked as "(fetched)".
- Never state a person's name, title or any personal detail unless a source
  confirms it. If you cannot confirm who currently holds a role, say so
  instead of guessing, and do not use a plausible-sounding name.
- Do not repeat a home address, personal phone number or other private
  contact detail even if a source shows one. The brief covers the
  organization, not the people in it.
- End with a section called "Could not confirm" naming anything you looked
  for but did not find a source for. An empty section still gets the heading,
  with one line saying nothing was left unconfirmed.
```

## Запустите его { #run-it }

Откройте новый чат с агентом и отправьте:

```text
Brief me on the Python Software Foundation before a call with them.
```

Любая известная публичная организация подойдёт так же: крупный фонд с открытым
исходным кодом — хороший вариант по умолчанию, потому что его финансы, совет и
миссия опубликованы и достаточно стабильны, чтобы их проверить.

## Проверьте результат { #check-the-result }

| Проверка | Образец |
| --- | --- |
| Каждое фактическое утверждение | Рядом стоит URL источника |
| Дата каждого утверждения | Указана дата самого источника или пометка «(fetched)», когда в источнике её нет |
| Названные люди | Только те, кого подтверждает источник, со ссылкой на собственную страницу организации, а не на догадку |
| Должность, которую никто не смог подтвердить | Сказано прямо, а не назван правдоподобный человек |
| Личные контактные данные | Отсутствуют, даже если источник их показал |
| Раздел «Не удалось подтвердить» | Присутствует и называет настоящий пробел, а не пуст по умолчанию |
| Тот же вопрос об организации почти без публичного следа | Агент говорит об этом и выдаёт короткую, честно скудную справку, а не выдумывает подробности, чтобы заполнить страницу |

!!! example "Записано на v0.0.504, 25 сентября 2026"

    Модель: Claude Sonnet 4.6 через OpenRouter. Агент выполнил три вызова
    `web_search`, затем `web_fetch` на собственных страницах PSF — «О нас»,
    «Совет» и годовой отчёт за 2024 год, — а также на публикации о программе
    грантов и агрегаторе Form 990. Один `web_fetch` (сайт с отчётностью) не
    удался, и его не повторили с другим источником для этого факта.

    Справка ссылалась на источник рядом с каждым утверждением — миссия,
    программы, финансы за 2024 финансовый год, общая сумма грантов за 2024 год
    и полный состав совета, — у каждого либо дата из источника, либо пометка
    «(fetched)». Совет был назван только по собственной странице состава PSF.
    Для человека с наибольшим вознаграждением, названного в сниппете поиска по
    Form 990, агент явно отказался указывать имя, потому что сама отчётность
    была недоступна напрямую, и перечислил этот пробел, а также точную разбивку
    выручки и даты следующего PyCon в разделе «Не удалось подтвердить».
    Стоимость: 0,26 USD.

## Когда что-то идёт не так { #when-it-goes-wrong }

- **Человек назван без источника рядом.** Ужесточите инструкции, чтобы источник
  требовался в точке утверждения, а не просто где-то в ответе: модель, которая
  прочитала имя мимоходом, исследуя другое, всё равно может повторить его не
  нарочно.
- **В справке нет раздела «Не удалось подтвердить».** Инструкции не выполнены,
  или не искали ничего, что могло бы правдоподобно отсутствовать, — проверьте
  вызовы инструментов в транскрипте, прежде чем доверять справке, которая нашла
  всё.
- **`web_fetch` не удался, и факт просто исчез.** Модель пошла дальше, а не
  попробовала второй источник. Попросите её назвать то, что не удалось получить,
  — именно так выглядел пробел с Form 990 в записанном запуске.
- **Финансовые факты или сведения о руководстве выглядят текущими, а им год.**
  Проверьте дату рядом с каждым: страница без даты публикации с приписанной датой
  получения — не то же утверждение, что страница с датой из источника.
- **У одной и той же организации при повторном запуске другой совет.** Результаты
  веб-поиска не стабильны между запусками; проверьте, со страницы какого
  источника пришло каждое имя, прежде чем доверять любой из версий, и
  предпочитайте собственную страницу организации сниппету поиска.

## Зафиксируйте проверку { #record-the-trial }

Сохраните вопрос, справку, источники, на которые она ссылается, запуск на странице
«Активность» с его вызовами инструментов и стоимость. Перед звонком человек всё
равно читает справку вместе с её источниками, решает, достаточно ли важен пробел
«не удалось подтвердить», чтобы поискать вручную, и никогда не повторяет
неподтверждённую личную подробность, даже если более поздний запуск уверенно её
называет.
