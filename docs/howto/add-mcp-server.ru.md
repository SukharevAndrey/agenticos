# Добавьте сервер в каталог MCP { #add-a-server-to-the-mcp-catalog }

[Каталог](../mcp.md#the-catalog) — это то, что делает выбор подключения полезным,
а не пустым полем для URL. Добавление записи — это данные, а не код: один объект
в `backend/app/core/catalog/mcp_servers.json`.

!!! tip "Чтобы пользоваться сервером, делать это не обязательно"

    Любой MCP-сервер, доступный по URL, подключается через запись *Свой сервер*,
    а его инструменты опрашиваются при подключении. Каталог избавляет кого-то
    от поиска URL и абзаца догадок о настройке; это не обязательное условие.

## Запись { #the-entry }

```json
{
  "key": "acme",
  "name": "Acme",
  "description": "Read and update work orders.",
  "category": "operations",
  "auth": "token",
  "url": "https://mcp.acme.com/mcp",
  "docs_url": "https://docs.acme.com/mcp",
  "token_hint": "A read-only service token from Settings → API, scoped to work orders.",
  "icon": "acme"
}
```

| Поле | |
|---|---|
| `key` | Стабильный идентификатор. Подключения его записывают, поэтому обращайтесь с ним так же, как с идентификаторами возможностей: имя меняйте свободно, `key` — никогда |
| `name` | Что показывает список выбора |
| `description` | Одно предложение в повелительном наклонении о том, что делают *инструменты* |
| `category` | Группирует список выбора. Используйте существующую категорию, если у сервера действительно нет своего места |
| `auth` | `none`, `token` или `oauth` |
| `url` | Пусто, когда сервер размещает клиент или поставщик выдаёт эндпоинт для каждой учётной записи, — тогда форма запросит её |
| `docs_url` | Где поставщик документирует свой сервер |
| `token_hint` | Только для `token`. См. ниже |
| `icon` | Имя `BrandIcon` или пусто |

!!! note "Проверяется при импорте"

    Файл сверяется с `CatalogEntry` при загрузке модуля, поэтому некорректная
    запись не даёт приложению запуститься, а не тихо исчезает из списка выбора.

## Напишите подсказку к токену { #write-the-token-hint }

!!! important "Именно это поле оправдывает запись"

    Общие инструкции — главная причина, по которой настройка токена не удаётся,
    а «API-токен» никому не говорит, куда нажимать.

Скажите, откуда берётся токен и что ему нужно уметь:

> Fine-grained personal access token с доступом на чтение к репозиториям,
> которые должен видеть агент.

Для `oauth` и `none` оставьте пустым — вставлять нечего.

## Значки { #icons }

`icon` задаёт имя фирменного знака. Если ни один встроенный набор значков его
не содержит, положите SVG в `backend/app/core/catalog/icons/<name>.svg` — его
отдаёт `GET /catalog/icons`, и он рисуется для любой записи каталога или
провайдера с совпадающим id.

Собственные цвета файла **игнорируются** — он рисуется силуэтом `currentColor`,
поэтому монохромная гамма консоли сохраняется по построению. Договор описан
в `icons/README.md`.

Пустой `icon` заменяется монограммой. Это намеренный облик, а не пропущенный:
любой набор значков конечен, а этот каталог — нет.

## Прежде чем закоммитить { #before-you-commit-it }

!!! warning "Запись — это обещание"

    Что кто-то посмотрел на сервер, что поток авторизации работает, что описание
    честное.
    Именно поэтому это список, который ведут вручную, а не зеркало публичного
    реестра, — так сделайте обещание правдой:

1. Подключите его в работающем экземпляре.
2. Запустите `POST /api/v1/mcp-connections/{id}/test` (**Проверить подключение**
   (Test)) и прочитайте список инструментов, который он вернёт. Если инструменты
   не совпадают с вашим `description`, исправьте описание.
3. Для `oauth` пройдите поток целиком, от начала до конца. Обнаружение,
   динамическая регистрация и обмен токеном — каждый из них ломается по-своему,
   а сервер, который застрял на втором шаге, в интерфейсе выглядит так же, как
   просто медленный.
4. Проверьте, что имя не совпадает с [префиксом инструментов](../mcp.md#name-collisions)
   существующей записи.
5. Запустите `uv run agenticos cmd mcp-catalog-check --source catalog`
   и убедитесь, что в отчёте запись помечена как проверенная, затем обновите
   встроенный снимок полным запуском с `--snapshot` — см.
   [как поддерживается каталог](../mcp.md#how-the-catalog-is-kept).

## Что менять не нужно { #what-does-not-need-changing }

Больше ничего. Список выбора строится по каталогу, а сервис подключений, опрос,
список разрешённых и префиксы — всё общее. Запись, добавленная здесь, появляется
в продукте при следующем перезапуске.
